Overview

This project aims to implement a 3D rendering pipeline, from creating mathematical spline representations using bezier curves, work with mesh data structure and implement phong shading, basic mesh edit operations like flip edge, split edge and subdivision. Whereas homework 1 focused on the image rasterisation aspects of the graphics pipeline, this homework focuses on the mathematical representation of 3D objects, and generating 3D meshes.

Overall, it was a challenging but rewarding project.

Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

Casteljau’s algorithm is a recursive method to generate bezier curves. For an n-degree Bezier curve with n edges, it recursively performs the n lerp subdivisions until it reaches a point, to trace the curve.

We implemented the algorithm by first iteratively interpolating across each pair of adjacent control points on one layer, then recursed to find the next layer of control points. We stop until the number of control points reaches 1.

Since each linear interpolation are parameterised by t, once the subdivisions are done, we can increment through them to trace out the final curve.

Part 2: Bezier surfaces with separable 1D de Casteljau

Briefly explain how de Casteljau algorithm extends to Bezier surfaces and how you implemented it in order to evaluate Bezier surfaces. Show a screenshot of bez/teapot.bez (not .dae) evaluated by your implementation.

De Casteljau's algorithm can be extended to generating Bezier surfaces by evaluating the surface in two stages, across parameters u and v. We implemented this using three core functions. First, evaluateStep performs a single level of linear interpolation between points, which evaluate1D uses in a loop to fully evaluate a 1D Bezier curve down to a single point. To evaluate the 2D surface, evaluate(u, v) sweeps along the u-axis by applying evaluate1D to each row of the control point grid, generating a moving set of intermediate control points. Finally, it sweeps along the v-axis by calling evaluate1D one last time on these intermediate points using parameter v to pinpoint the exact 3D surface position.
